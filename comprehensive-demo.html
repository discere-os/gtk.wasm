📋 Demo Overview

This comprehensive demo showcases all major GTK4 rendering capabilities in a single C application. The demo is organized into multiple tabs demonstrating different aspects of the GTK stack.

Page 1: Widget Gallery

  • 5 styled buttons (Primary, Secondary, Success, Danger, Warning)
  • Text entry with placeholder and activation handling
  • Horizontal scale/slider with value display
  • 3 toggle switches with labels
  • Progress bar showing completion state
  • Animated spinner widget
  • Live status label showing widget interactions

Page 2: Text Rendering

  • Multi-line text view with word wrapping
  • Multiple font families (Sans, Serif, Monospace)
  • Font attributes (bold, italic, underline)
  • Unicode text (Chinese, Arabic, Hebrew)
  • Right-to-left text support
  • Ligatures and kerning demonstrations
  • Variable text sizes
  • Monospace code blocks

Page 3: Cairo Graphics

  • Custom drawing area (400x300px)
  • Linear gradient backgrounds
  • Basic shapes (circles, rectangles, triangles)
  • Pango text integrated with Cairo
  • Rotated and transformed text
  • Bezier curves and paths
  • Color blending and transparency

Page 4: Layout Demo

  • Grid layout manager (3x4 grid)
  • Automatic spacing and alignment
  • Responsive widget arrangement

💻 Source Code

Complete C implementation using GTK4 APIs. This is pure C code, not TypeScript!

/* GTK Comprehensive Rendering Demo */ #include <gtk/gtk.h> #include <gdk-pixbuf/gdk-pixbuf.h> #include <cairo.h> #include <pango/pango.h> /* Cairo custom drawing */ static void draw_function( GtkDrawingArea *area, cairo_t *cr, int width, int height, gpointer data) { /* Draw gradient */ cairo_pattern_t *gradient = cairo_pattern_create_linear(0, 0, width, height); cairo_pattern_add_color_stop_rgba( gradient, 0, 0.2, 0.4, 0.8, 0.3); /* ... shapes, text, curves ... */ } /* Widget event handlers */ static void on_button_clicked( GtkButton *button, gpointer data) { const char *text = gtk_button_get_label(button); /* Update status label */ } int main(int argc, char *argv[]) { GtkApplication *app; app = gtk_application_new( "org.discere.gtk.demo", G_APPLICATION_DEFAULT_FLAGS); g_signal_connect(app, "activate", G_CALLBACK(activate), NULL); return g_application_run(app, argc, argv); }
